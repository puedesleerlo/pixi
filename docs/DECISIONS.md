# Decisions and deviations from the spec (kept honest for the Q&A)

| # | Decision | Why |
|---|---|---|
| 1 | **Conver 1760 scans** come from Wikimedia Commons files `… Nicolas Conver Tarot 1760.jpg`. The 1760 artwork is public domain; the uploader tags the scan CC BY‑SA 4.0, so every Conver caption says "public‑domain artwork · scan CC BY‑SA 4.0 via Wikimedia Commons". | Spec asks for BnF Gallica; the Gallica scans on Commons are 132 unlabelled pages and could not be mapped to cards in the time available. |
| 2 | **Null table keyed by N.** Silhouette is scale‑invariant, so rescaling the isotropic null to the observed V does not change the max‑silhouette distribution; `S_null95` therefore depends only on N and is precomputed for N = 8..80 (`api/pixie/null_table.json`, 200 draws each). The rescale step is still in the code so it matches the spec text. | 200 draws × KMeans(k=2,3, n_init=10) per reveal is seconds, not milliseconds. |
| 3 | **Replay readings live inside the room document**, never in `readings`. | They are copies of real readings; storing them would double‑count in the grammar and verdict. |
| 4 | **Replay fallback**: if no real round exists anywhere, replay six seed readings of the best‑covered card, labelled synthetic. | Replay must work at 3 am with zero real data. |
| 5 | **Lazy ticks**: a round moves `reading → reveal` on the next request after `round_ends_at` or after the last reader submits. No background tasks. | Spec: polling, no websockets; nothing to crash. |
| 6 | **No shadcn/ui**; Tailwind utilities + five small components. | Setup time; the design direction (line art on off‑white, one accent) is easier to hold without a component kit. |
| 7 | **Store**: `MONGODB_URI` → Atlas; otherwise memory + JSON snapshot (`api/.pixie_state.json`). Corpus and seeds are upserted into whichever store is live. | The demo must not depend on the network. |
| 8 | **Embeddings**: MiniLM locally (`sentence-transformers/all-MiniLM-L6-v2`, 384‑d). `PIXIE_EMBED=hash` forces a deterministic hashed bag‑of‑words fallback with the same dimensionality (tests, machines without torch). | Spec §4; never Gemini embeddings. |
| 9 | **Cluster naming**: K2 only when `K2_ENDPOINT` is set (OpenAI‑compatible chat endpoint, 3 s timeout); else the two‑pole template. Every label carries `label_by`. | Spec §6.6; the model never scores. |
| 10 | **`you.role`** in the room view is `host`/`player` in the lobby and `maker`/`reader`/`spectator` during rounds; `you.is_host` is always present. | The host can also be the maker. |
| 11 | **Gemini tagging** is a script (`api/scripts/tag_with_gemini.py`) that writes a JSON file; the shipped `card_elements.json` is human‑tagged (`tagged_by: "human"`) because no key was available at build time. Run the script with a key and `--apply` to get `tagged_by: "gemini"` rows. | Spec §4: one cached batch pass; human corrections are edits to the JSON. |
| 12 | **Maker points** are computed in the `on_reveal` callback at the moment of the transition and frozen in `room.history`; the reveal payload recomputes distances live (same numbers unless the dev panel changes weights mid‑round). | Scores die with the room; the record must not drift. |

## v4 (Relay + Decks) — added at the pivot, Sat ~01:40

| # | Decision | Why |
|---|---|---|
| 13 | **Seeds**: 60 composed cards, 300 v0 readings, plus 40 edits × 4 paired readers × 2 reads = 620 synthetic readings in the Playground deck. corr(W, W*) = 0.92–0.95 across seeds 0–4. | Spec §6.7 lists the 40 paired edits beside the 300 readings; reading them as additional keeps the v0 grammar test identical to v2. |
| 14 | **Paired-estimate test criterion**: the pooled bootstrap CI widened by two paired standard errors (tol 0.6), ≥ 80 % of edited elements inside on ≥ 6 of 8 axes; plus corr(paired effects, W*) > 0.85. Empirically 0.90–1.00 and 0.94–0.96. | The literal "inside the pooled CI" holds for only 31–48 % by construction: the pooled CI carries none of the paired estimate's own noise (4 pairs, sd 0.3). |
| 15 | **Slot rule**: `large` may go in any slot; `small` never in `center`; a composition with no `large` element leaves the center empty (max 4). | Contract §2; the spec's "center takes large only" is satisfied, and 14 Smith elements are center-eligible. |
| 16 | **Readers per version = players − holder.** In a 3-player room the maker reads their own card once an editor holds it. The maker score needs ≥ 3 readers, so it only awards points in rooms of 4+; smaller rooms still get the reveal. | Spec §7.1 ("everyone not holding the card is a Reader") and §6.3 (N ≥ 3). The demo has three judges + a teammate maker. |
| 17 | **Editor rotation** skips the maker: next player after the current holder in join order who is not the maker. Edit budget counts edits (v1..v3). | A maker editing their own card would not be a second encoder. |
| 18 | **Reveal numbers are frozen** in `round.result` at the moment the read phase ends (points applied once); the reveal payload reuses them. Chains recompute from stored readings, so they agree unless the dev panel changes weights. | Scores must not drift while people look at them. |
| 19 | **Intent visibility**: readers see the star on the PCA plot and unsigned gap bars, never the statement or signed gaps, until the card lands or closes; the holder (maker/editor) sees statement, axes, signed gaps and current fidelity. | Readers re-read the same card after an edit; knowing the intent would contaminate the second read. |
| 20 | **Replay** re-plays a finished card version by version (readings arriving over 10 s, 12 s reveal each); falls back to any room's finished card, then to a seeded card with an edit, marked synthetic. Never scores, never stores. | Demo survival with zero real data. |
| 21 | **Smith crops are coloured** rectangles from the 1909 Commons scans (the line art was printed in colour); Marseille elements are text tiles until bboxes are added. Every crop caption names card, deck, year and rights. | "Crops or text tiles — every metric survives either way." |
| 22 | **Deck mode (T2) shipped minimal**: compose, read queue (fewest human readings, skips cards you read or made), lock on `ready_threshold` with optimistic `version_id`, `approved_editors`. No edit requests, no branches. | Spec §7.2; cut order says deck-mode lock goes last. |
| 23 | **Generated symbols (T2) not built** at this point; the element schema, community library per deck, `origin: "generated"` and the grammar's `historical_support: null` path are in place. | Needs an image-generation key; never on the demo path. |
| 24 | **Synthetic rows are down-weighted in the ridge** (`w_synthetic = 0.25`, dev panel). The 620 seed readings are a prior drawn from the tradition; real readings are data and should pull the coefficients visibly as they accumulate. Consequence, stated honestly: after one round of three real readings the edited symbol's **coefficient moves**, but its bootstrap band may widen (three high-leverage rows) — it narrows as real readings accumulate, not within a single round. The reveal animates before → after either way. | Equal weights would hide any drift from tradition until ~100 real readings; the demo has to show the deck learning. |
| 25 | **API host resolved at runtime**: if `NEXT_PUBLIC_API_URL` points at localhost but the page was opened from another host (a phone on the LAN), the web app calls the API on that host; image URLs are returned relative (`/static/…`) and prefixed by the web app. The API binds `0.0.0.0`. | Safari's "Load failed" on phones: a phone cannot reach the laptop's localhost. |
| 26 | **Maker's compose screen is a guided three-step flow** (meaning → scales → symbols) with a "how your turn works" box, per-step completion, and a sticky footer whose button names the next missing step. | First playtest: the maker side was not easy to understand. |

## v5 (platform) — branch `v5`, started Sat 02:40

| # | Decision | Why |
|---|---|---|
| 27 | **`main` keeps the v4 hackathon relay; v5 is built on branch `v5`** in the spec's slice order. | Judging is at 16:00; the working demo must survive the platform build. |
| 28 | **Every third-party service has a local fallback selected by env** (contract §2): dev magic link instead of Auth0/mail, `LocalStorage` under `api/storage/` instead of S3, `LocalCollageProvider` (Pillow compositing) instead of Gemini/FLUX/OpenAI, perceptual image embedding instead of CLIP when weights are absent, declared-only symbol detection instead of the Gemini tagger, template names instead of K2. `/api/health` names every backend in use. | No keys were available at build time, and the demo path must work with every API down. The adapters for the real services are implemented and activate on their env vars. |
| 29 | **No JSON-Schema codegen**: Pydantic models in `api/models.py` and TypeScript in `web/src/lib/types.ts`, both using the spec's names verbatim. | Codegen tooling costs more than it saves at this size; the spec is the schema. |
| 30 | All API routes are mounted under `/api` (the spec's paths are relative to it). | One prefix for CORS, proxies and the runtime host resolution from v4. |
| 31 | Jobs run in a thread pool inside the API by default (`PIXIE_WORKER=thread`), inline in tests, or in `worker.py` as a separate process; SSE is implemented by polling the job document every 0.5 s. | Same semantics as the spec's queue with zero infrastructure; a Mongo-backed queue works unchanged when `MONGODB_URI` is set. |
| 32 | Base decks at launch: Smith 1909 and Conver 1760 with whatever Commons verifies (never a guessed URL); the other eight catalog rows are manifests with `status: planned`. | Rights and provenance must be checked per card; the v4 verification pipeline is reused. |
| 33 | **Web-facing routes beyond the spec** (`/api/me/decks`, `/api/me/inbox`, `/api/me/activity`, `/api/structure-templates`, `/api/decks/preview-style`, `GET /api/decks/{id}/sessions`, `/api/auth/auth0/login`) live in `routers/me.py`. | The front end needed them; the spec's §11 list is the minimum. |
| 34 | **Style preview** in the wizard renders a quota-free card with the local collage provider from the base deck's exemplars, even when a real image provider is configured. | Instant, deterministic, and never spends quota (spec §5.2 step 4). |
| 35 | **Export** fetches base-deck images from Commons at export time (`PIXIE_EXPORT_FETCH=0` disables; the manifest always carries the URLs); print sheets are letter pages at 300 dpi, 9 cards with crop marks, written by Pillow as a multi-page PDF. | No extra dependency; images are immutable per version so the fetch is reproducible. |
| 36 | **Synthetic playground fidelity** falls back to synthetic readings when a version has no human ones, so the demo deck's transmission tab is not empty; real decks use human readings only. | Spec §8.2 defines F over human readings; the playground is the one deck that has none. |
